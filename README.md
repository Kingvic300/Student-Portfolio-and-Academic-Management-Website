## Pages

| Page | File | Features |
|------|------|----------|
| Home | `index.html` | Name, photo, welcome message, biography |
| About Me | `about.html` | Education table, career goals, skills, hobbies, audio |
| Projects | `projects.html` | Three projects with images, descriptions and links |
| Planner | `planner.html` | Add, complete and delete tasks (JavaScript) |
| Contact | `contact.html` | Form with JavaScript validation |

## Structure

```
css/style.css     external stylesheet (Flexbox, Grid, media queries, transitions)
js/main.js        menu toggle, active link, greeting
js/planner.js     task manager (arrays, functions, DOM updates)
js/contact.js     form validation
images/           photo and project screenshots
media/            audio file
```
